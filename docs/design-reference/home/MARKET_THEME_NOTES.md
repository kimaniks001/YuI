# Market Theme Notes

SecurePay does not wear costumes. The Market has seasons.

The Home layout, navigation, agreement meaning, status meaning and official SecurePay logo remain stable. Only atmosphere may change.

Initial stable theme set for later implementation:

1. **Market Day** — everyday SecurePay; warm off-white, SecurePay green, restrained orange, lively icon accents.
2. **Green Market** — calm growth; deeper greens, leaves/tree motifs, very restrained orange.
3. **Town Market** — modern builders and business; stronger charcoal geometry with green/orange accents.
4. **Evening Market** — premium calm; deep forest/charcoal atmosphere with illuminated cream surfaces.

Temporary national/seasonal moments may alter only decorative background motifs and the short welcome treatment. Core meanings, financial states and action semantics never change with a theme.

The approved opening-animation reference is stored beside this file. Future implementation should use a short, skippable transition and respect `prefers-reduced-motion`.
