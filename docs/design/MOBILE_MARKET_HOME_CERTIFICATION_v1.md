# V1 — Mobile Market Home Certification v1

**Status:** Implementation complete; awaiting human visual approval on target phones.
**Date:** 21 August 2026

## Locked information order

1. Welcome to the Market
2. “What are you here to do today?”
3. natural-language intention box
4. compact Living SecurePay reaction
5. Work & Trade / Life & Support switch
6. familiar choices
7. full illustrative “SecurePay understood” demo
8. optional deeper explanation

The full demo is deliberately below the two Market families so the trader sees both trade and human-life possibilities early.

## Batch 1 changes

- Replaced the generic sparkle in the compact live reaction with the Living SecurePay Mark.
- The mark listens/guides; it does not claim financial confirmation.
- Replaced the mobile full-demo shield with the Living SecurePay Mark while leaving the approved desktop demo unchanged.
- Kept the approved full SecurePay wordmark in the signed-out Market entrance header.
- Added a 420-character input ceiling and fixed two-row starting area so long intentions remain controllable.
- Added keyboard/focus scroll margin and bounded mobile textarea scrolling.
- Added compact-height rules for 360×800 and 390×844 class devices.
- Added breathing-room rules for 412×915 and 430×932 class devices.
- Raised the readability floor for Work & Trade / Life & Support labels and familiar-choice labels.
- Kept minimum touch targets at 44 px.
