# Agreement Creation Visual Lock v1

## Locked principle
Agreement creation is a guided conversation, not an exam room.

## Sequence
Natural intention → SecurePay understood → only missing questions → review → create.

## Living Mark behaviour
- Listening: SecurePay is interpreting the trader's intention.
- Guiding: ordinary creation questions and final review.
- Caution: the requested structure cannot safely continue.
- Complete: agreement creation itself completed.

A completion mark for agreement creation never means funded, Payment Ready, released or settled.

## Room behaviour
- Preserve what the trader already said.
- One clear decision at a time on mobile.
- Keep correction/back behaviour visible.
- Remind the trader that answering questions does not move money.
- Encourage without childish gamification.
- Use semantic icons for the trade story while the SecurePay mark carries SecurePay status/guidance.

## Review route
- `/preview/create`

The preview may illustrate the creation journey but must not manufacture backend financial authority.
